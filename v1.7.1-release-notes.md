# synthux v1.7.1 — Chrome Web Store Patch Release

## 🇬🇧 English

### What's Fixed in v1.7.1

**MV3 Compliance Fix (Blue Argon)**

Chrome Web Store rejected v1.7.0 due to remotely hosted code detected in the jsPDF bundle (violation reference: Blue Argon). The scanner flagged `createElement("script")` + `.src` assignment patterns inside jsPDF's `pdfobjectnewwindow` code path, even though synthux never uses that output mode (only `'blob'`).

**Root Cause:**
The previous esbuild plugin only stripped the CDN URL string (`cdnjs.cloudflare.com/ajax/libs/pdfobject/...`) but left the dynamic `<script>` element creation and `.src` assignment code intact. The CWS automated scanner detects these patterns regardless of the actual URL value.

**Fix:**
The esbuild build plugin now replaces the entire `pdfobjectnewwindow` and `pdfjsnewwindow` case blocks with `throw new Error(...)` statements at build time. This removes all:
- CDN URL references
- `createElement("script")` calls
- Dynamic `.src` assignments
- `createElement("iframe")` with external viewer URLs

The extension's PDF export continues to work normally via `doc.output('blob')` which is fully local.

### Files Changed
- `esbuild.config.js` — Enhanced MV3 compliance plugin to strip entire dead code blocks
- `extension/manifest.json` — Version bump 1.7.0 → 1.7.1
- `CHANGELOG.md` — Added v1.7.1 entry

## 🇹🇷 Türkçe

### v1.7.1'de Düzeltilenler

**MV3 Uyumluluk Düzeltmesi (Blue Argon)**

Chrome Web Store, jsPDF paketi içinde uzaktan barındırılan kod tespit ettiği için v1.7.0'ı reddetti (ihlal referansı: Blue Argon). Tarayıcı, jsPDF'in `pdfobjectnewwindow` kod yolundaki `createElement("script")` + `.src` atama kalıplarını yakaladı — synthux bu çıktı modunu hiçbir zaman kullanmamasına rağmen (sadece `'blob'` kullanıyor).

**Kök Neden:**
Önceki esbuild plugin'i yalnızca CDN URL dizesini (`cdnjs.cloudflare.com/ajax/libs/pdfobject/...`) siliyordu, ancak dinamik `<script>` elementi oluşturma ve `.src` atama kodunu olduğu gibi bırakıyordu. CWS otomatik tarayıcısı, gerçek URL değerinden bağımsız olarak bu kalıpları algılıyor.

**Düzeltme:**
Esbuild build plugin'i artık `pdfobjectnewwindow` ve `pdfjsnewwindow` case bloklarının tamamını build sırasında `throw new Error(...)` ifadeleriyle değiştiriyor. Bu şekilde aşağıdakilerin tümü kaldırılıyor:
- CDN URL referansları
- `createElement("script")` çağrıları
- Dinamik `.src` atamaları
- Harici görüntüleyici URL'leriyle `createElement("iframe")`

Uzantının PDF dışa aktarma özelliği, tamamen yerel olan `doc.output('blob')` üzerinden normal şekilde çalışmaya devam ediyor.

### Değişen Dosyalar
- `esbuild.config.js` — MV3 uyumluluk plugin'i ölü kod bloklarının tamamını silecek şekilde güçlendirildi
- `extension/manifest.json` — Sürüm 1.7.0 → 1.7.1
- `CHANGELOG.md` — v1.7.1 girişi eklendi
