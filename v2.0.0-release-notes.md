# synthux v2.0.0 — Sectoral Rule Packs, Plugin Ecosystem, Enhanced Reporting & 2026 Local LLMs

**Release Date:** 2026-11-02

## What's New in v2.0.0

### 🧩 Sectoral Rule Packs & Custom JSON Plugin Ecosystem
Evaluate pages not only with universal usability heuristics, but also with domain-specific UX audit frameworks:
- **Nielsen's 10 Heuristics** (`nielsen-10.json`) — Universal usability evaluation (Jakob Nielsen, 1994).
- **E-Commerce & Checkout UX** (`ecommerce.json`) — Cart friction, pricing transparency, guest checkout, product gallery clarity, search & filtering, and trust signals (Baymard-aligned).
- **SaaS & Dashboard UX** (`saas.json`) — Empty states & onboarding, data density & visual hierarchy, bulk actions & power-user shortcuts, permission clarity, and destructive action guardrails.
- **Fintech & Banking UX** (`fintech.json`) — Fee & rate transparency, transaction confirmation & irreversibility warnings, security & session reassurance, numeric input formatting, and error recovery.
- **Custom JSON Rule Pack Importer** — Import, select, and delete community or organization-specific `.json` rule packs directly in the Scanner tab, plus download a starter JSON template with one click.

### 📊 Enhanced Reporting (PDF & Markdown v2.0)
Richer, client-ready UX audit exports across both the Side Panel and Flow Builder:
- **Executive Summary & Prioritized Action Plan (P0 / P1 / P2)** — Automatic severity-based prioritization table (`P0 Immediate`, `P1 High Priority`, `P2 Backlog`).
- **Heuristic Breakdown Table** — Score, progress bar, status badge, and issue counts per heuristic.
- **Annotated Visual Audit Page in PDF** — Embeds the full annotated viewport screenshot with numbered severity markers directly into the PDF report.
- **Rule Pack Metadata** — Displays the active Rule Pack badge and evaluation mode in PDF cover/headers and Markdown front-matter.
- **Enhanced Flow Builder Exports** — Multi-page Flow PDF and Markdown exports now include a **Page Score Comparison Matrix**, **Cross-Page Consistency Synthesis**, and a **Prioritized Flow Action Plan**.

### 🤖 2026 Local LLM Lineup (Ollama Vision & Reasoning)
Updated local model recommendations and defaults for 2026:
- **Default model updated to `gemma4`** (`ollama pull gemma4`) with `gemma4:e4b` lightweight edge variant.
- Added **`qwen3.8`**, **`qwen3.5`**, **`llama4:scout`**, and **`deepseek-r1`** recommendations across the Settings UI, Onboarding Guide, Website, and README.
- **Reasoning `<think>...</think>` Sanitizer** — Automatically strips `<think>` blocks emitted by reasoning models (`deepseek-r1`, `qwen3.8`, `gemma4`) before JSON parsing so structured heuristic and flow outputs never fail to parse.

### 🐛 Stability & Bug Fixes
- **Annotated Screenshot Horizontal Scroll Fix** — Fixed X-coordinate offset when capturing element bounding boxes on horizontally scrolled pages and clamped edge badges inside the canvas.
- **Flow Builder Page Node Thumbnails** — Fixed `thumbnail` property mapping when adding live tabs to the Flow canvas so page preview thumbnails render reliably.
- **Flow Builder Claude Provider Label** — Added missing `claude` provider label in Flow Receipt modal.
- **CORS Error Banner Detection** — Fixed payload inspection (`message.payload?.errorType === 'cors'`) so the Ollama CORS troubleshooting banner reliably appears when `OLLAMA_ORIGINS` is missing.
- **Context Menu Integration** — Registered `"Analyze in synthux Flow"` context menu item with `contextMenus` permission in `manifest.json`.
