How Dual-Engine Accessibility Works

Technical Compliance Meets Real Assistive-Tech Usability

synthux inspects both the underlying DOM tree and the rendered visual experience to catch barriers static scanners miss.

01 · Deterministic DOM Audit

axe-core WCAG 2.1 / 2.2 AA Rule Engine

Detects missing form labels, invalid ARIA attributes, insufficient color contrast, missing document language tags, and duplicate IDs with impacted element selectors and W3C links.

02 · Contextual AI Evaluation

Screen-Reader & Keyboard Persona Simulation

Adopts the Accessibility User persona (JAWS/NVDA/VoiceOver + Tab-only navigation) to evaluate heading hierarchy comprehension, skip-link availability, and focus indicator visibility.

03 · Remediation Ready

Before/After ARIA & CSS Code Fixes

Generates concrete HTML, ARIA, and CSS fixes for every accessibility violation and highlights the exact element on the live page when you hover in the report.

Target Audience · Compliance & QA

Accessibility Specialists, GovTech & Enterprise QA

Organizations preparing for European Accessibility Act (EAA), Section 508, EN 301 549, and ADA audits across public portals, banking apps, and e-commerce sites.

  • Export combined WCAG + Heuristic PDF compliance reports
  • Prioritize critical blockers with the P0/P1/P2 Action Plan
Target Audience · Frontend & Design

UI Engineers & Design System Maintainers

Component library authors verifying that modals, dropdowns, data tables, and custom controls maintain proper focus management and contrast in both light and dark themes.

  • Catch contrast and ARIA regressions on localhost before merge
  • Use Hover-to-Highlight to locate hidden or unlabelled DOM nodes
Synthetic AI Persona · Built-In

Accessibility User (Screen Reader & Keyboard Only)

Evaluates the page as a user navigating exclusively with VoiceOver/NVDA and keyboard keys (Tab, Shift+Tab, Enter, Escape, Arrow keys) with low vision.

  • Audits semantic landmarks (<header>, <nav>, <main>) and heading levels
  • Flags non-descriptive link text ("Click here") and missing alt attributes
Synthetic AI Persona · Custom Profile

Motor & Cognitive Accessibility Personas

Build custom personas combining specific age ranges (e.g. 65+) with motor or cognitive accessibility profiles to test click-target sizing and plain-language clarity.

  • Detects cramped interactive controls that violate target-size guidelines
  • Identifies distracting animations, auto-advancing carousels, and dense copy
Accessibility Audit FAQ

Frequently Asked Questions

Does axe-core run automatically during every synthux scan?

Yes. Every page scan runs deterministic axe-core WCAG 2.1/2.2 Level A & AA checks alongside your selected AI personas and UX rule pack.

Are WCAG violations included in the exported PDF and Markdown reports?

Yes. Both PDF and Markdown exports include a dedicated WCAG Accessibility Audit section detailing impact severity, affected element counts, and remediation links.
