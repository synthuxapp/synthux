# synthux v1.7.0 — Chrome Web Store Release Notes

## 🇬🇧 English

### What's New in v1.7.0

**WCAG Audit (axe-core)**
Full WCAG 2.2 AA compliance testing is now built-in. axe-core runs automatically during every analysis and reports violations with impact severity (critical/serious/moderate/minor), affected elements, WCAG references, and direct links to fix documentation. Results appear in the report UI, Markdown, and PDF exports.

**Custom Synthetic User Profiles**
Create up to 5 custom user personas beyond the built-in profiles. Define age range, tech savviness, accessibility needs, and specific goals. Custom profiles are fully integrated into analysis — results appear with full persona context in reports and exports.

**Custom Analysis Mode**
A new third mode alongside Quick and Deep. Pick exactly which Nielsen heuristics you want to evaluate using toggle chips. Perfect for focused audits on specific areas like accessibility or error handling.

**Dynamic Time Estimates**
Analysis duration is now calculated dynamically based on your selection: number of profiles × number of heuristics × provider speed. No more guessing — see realistic estimates before you start.

**Bug Fixes**
- Fixed PDF export crash (COLORS.secondary error)
- Fixed text overflow in PDF custom profile subtitles
- Settings version now reads from manifest automatically

### Updated Description

synthux evaluates web pages using Nielsen's 10 Usability Heuristics, WCAG 2.2 accessibility audit (axe-core), and synthetic user profiles — powered by local AI (Ollama) or cloud APIs (Gemini, OpenAI, Claude).

## 🇹🇷 Türkçe

### v1.7.0'daki Yenilikler

**WCAG Denetimi (axe-core)**
Tam WCAG 2.2 AA uyumluluk testi artık yerleşik. axe-core her analizde otomatik çalışır ve ihlalleri etki derecesi (kritik/ciddi/orta/düşük), etkilenen öğeler, WCAG referansları ve düzeltme dokümanlarına doğrudan bağlantılarla raporlar. Sonuçlar rapor arayüzünde, Markdown ve PDF dışa aktarımlarında görünür.

**Özel Sentetik Kullanıcı Profilleri**
Yerleşik profillerin ötesinde 5'e kadar özel kullanıcı personası oluşturun. Yaş aralığı, teknoloji yetkinliği, erişilebilirlik ihtiyaçları ve özel hedefler tanımlayın. Özel profiller analize tam olarak entegredir — sonuçlar raporlarda ve dışa aktarımlarda tam persona bağlamıyla görünür.

**Özel Analiz Modu**
Hızlı ve Derin modların yanında yeni üçüncü mod. Toggle butonlarla hangi Nielsen sezgisellerini değerlendirmek istediğinizi seçin. Erişilebilirlik veya hata yönetimi gibi belirli alanlara odaklı denetimler için ideal.

**Dinamik Süre Tahmini**
Analiz süresi artık seçiminize göre dinamik olarak hesaplanır: profil sayısı × sezgisel sayısı × sağlayıcı hızı. Başlamadan önce gerçekçi tahminler görün.

**Hata Düzeltmeleri**
- PDF dışa aktarma çökmesi düzeltildi (COLORS.secondary hatası)
- PDF özel profil altyazılarında metin taşması düzeltildi
- Ayarlar sayfası sürüm numarası artık manifest'ten otomatik okunuyor

### Güncel Açıklama

synthux, web sayfalarını Nielsen'ın 10 Kullanılabilirlik Sezgiseli, WCAG 2.2 erişilebilirlik denetimi (axe-core) ve sentetik kullanıcı profilleri kullanarak değerlendirir — yerel yapay zeka (Ollama) veya bulut API'leri (Gemini, OpenAI, Claude) ile çalışır.
