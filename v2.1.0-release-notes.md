# synthux v2.1.0 — Model Context Protocol (MCP) Server, Chrome Extension Agent Bridge & Loopback Security Hardening

**Release Date:** 2026-11-09

## What's New in v2.1.0

### 🔌 Model Context Protocol (MCP) Server & Chrome Extension Agent Bridge (`synthux-mcp`)
Desktop AI coding agents (**Google Antigravity / Gemini 4 Argon**, **Claude Desktop**, **Claude Code**, **Cursor**, **OpenAI Codex**, **Windsurf**) and local LLM MCP hosts can now orchestrate 100% of `synthux` features inside your live Chrome browser:
- **Zero-Dependency MCP Server (`npx synthux-mcp`):** Supports both **Stdio** (`stdin`/`stdout`) and **Streamable HTTP (`http://127.0.0.1:17483/mcp`)** alongside a local WebSocket bridge (`ws://127.0.0.1:17483/ws`) to the Chrome extension's MV3 Service Worker.
- **14 MCP Tools for Complete Browser Control:**
  - `get_extension_status` & `list_browser_tabs`
  - `open_and_audit_url` — Open any URL in Chrome, wait for DOM readiness, and run an audit or prepare an Agent-Brain bundle.
  - `scan_page_ux_context` & `run_wcag_audit` — Extract live DOM metrics, contrast ratios, forms, and `axe-core` WCAG 2.2 AA violations.
  - `run_ux_audit` — Trigger Quick, Deep, or Custom heuristic evaluations with any Sectoral Rule Pack (`nielsen-10`, `ecommerce`, `saas`, `fintech`, or custom JSON) and Synthetic Persona.
  - `prepare_external_audit` & `submit_external_audit` — **Agent-Brain Mode**: Let your host AI agent (e.g., Antigravity / Gemini 4 Argon, Claude, Cursor) evaluate the live DOM + WCAG + Screenshot using its own LLM brain with zero extra API keys required, then sync the resulting v2.0 report directly to the Chrome Side Panel UI.
  - `start_flow_analysis` — Run multi-page User Journey (Flow Builder) evaluations across 2+ URLs.
  - `toggle_heatmap`, `highlight_issue`, `capture_annotated_screenshot` — Control live severity heatmaps, highlight specific CSS selectors on the page, and capture numbered visual audit PNGs.
  - `manage_rule_packs`, `manage_personas`, `configure_ai_provider`, `get_report_history`.

### 🛠️ In-App MCP Agent Bridge Settings & Setup Guide
- Added a dedicated **MCP Agent Bridge** section in **Settings (`synthux-settings`)**:
  - Enable/disable toggle (`mcpEnabled`) and live WebSocket connection status indicator (`Connected · 127.0.0.1:17483` / `Standby`).
  - Optional Security Pairing Token (`SYNTHUX_MCP_TOKEN`) input.
  - Collapsible quick-start guide with 1-click copy buttons for `mcp_config.json` (Stdio) and Streamable HTTP (`http://127.0.0.1:17483/mcp`).
- Updated the Side Panel header connection pill to display `Connected · MCP` or `MCP Agent Ready` when the MCP bridge is active.

### 🔒 Privacy & Loopback Security Hardening
- **Strict Loopback Binding (`127.0.0.1`):** Both `mcp/server.js` and `extension/core/mcp-bridge.js` (`isLoopbackWsUrl`) enforce local loopback addresses (`127.0.0.1` / `localhost` / `[::1]`) and reject remote WebSocket endpoints.
- **Cross-Site WebSocket Hijacking (CSWSH) & Origin Firewall:** `mcp/server.js` inspects the `Origin` header on every HTTP and WebSocket request and blocks all `http://` and `https://` web page origins (`403 Forbidden`), ensuring no visited website can interact with the local MCP server.
- **Zero API Key Exposure:** Stored BYOK API keys (`gemini`, `openai`, `claude`) are never returned over MCP tools.
- **Safe Tab Filtering:** Automatically blocks `chrome://`, `chrome-extension://`, `edge://`, `about:`, `file://`, and Chrome Web Store pages from external scanning.
