# synthux v1.8.0 — Page Overlay & Visual Feedback

**Release Date:** 2026-05-16

## What's New

### 🔥 Issue Heatmap
Toggle a live heatmap overlay directly on the analyzed page. Critical issues glow red, moderate yellow, minor green — see problem density at a glance. Turn it on/off anytime from the report view using the new switch toggle.

### 🎯 Hover-to-Highlight
Hover any issue in the report sidebar to instantly highlight the affected element on the live page. The overlay shows:
- Severity-colored border (red = critical, yellow = moderate, green = minor)
- Tooltip with issue description
- Smooth scroll into view for off-screen elements

### 📸 Annotated Screenshots
New `captureAnnotatedScreenshot()` function generates viewport screenshots with numbered severity markers at issue element positions — ready for PDF reports.

### 🧩 Page Overlay System
A new unified overlay manager (`overlay-manager.js`) is injected into target pages on demand. It handles highlight borders, heatmap canvas rendering, and annotation markers with proper z-index isolation, then cleans up automatically when the panel closes.

### 🧠 Smarter AI Prompts
AI prompt now explicitly requires valid CSS selectors in the `element` field (rule #8), enabling accurate page highlighting. Fuzzy selector matching handles cases where AI returns descriptive references instead of exact selectors.

## Technical Details

### Files Changed
- `extension/content/overlay-manager.js` — NEW: Self-contained overlay system (highlight, heatmap, annotations)
- `extension/background/service-worker.js` — Overlay message relay (side panel ↔ content script)
- `extension/core/heuristics.js` — CSS selector prompt enhancement
- `extension/core/screenshot.js` — Annotated screenshot capture
- `extension/core/ai-client.js` — HTTP status debug logging
- `extension/core/analyzer.js` — Debug logging for analysis pipeline
- `src/sidepanel/components/synthux-report.js` — Heatmap switch, hover events, overlay methods
- `extension/manifest.json` — Version bump to 1.8.0
- `README.md` — New features, overlay docs, updated roadmap
- `website/index.html` — New feature cards, version badges

### Architecture
```
Side Panel (report)
    ↕ chrome.runtime.sendMessage
Service Worker (relay)
    ↕ chrome.tabs.sendMessage + chrome.scripting.executeScript
Overlay Manager (page)
    → highlight overlay (DOM)
    → heatmap canvas (Canvas 2D)
    → annotation markers (OffscreenCanvas)
```

## CORS Note
Ollama users must set `OLLAMA_ORIGINS="*"` and restart Ollama. This is required because Chrome extensions send requests from `chrome-extension://` origins, which Ollama's default configuration rejects.
