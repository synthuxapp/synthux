# synthux v1.9.0 — Flow Builder & Multi-Page Analysis

**Release Date:** 2026-06-09

## What's New

### 🔀 Flow Builder
Figma-style visual canvas for mapping multi-page user journeys. Drag-and-drop page nodes on an infinite dotted canvas, draw connectors between pages, and add sticky notes with context for the AI to consider during analysis.

### 🧠 Cross-Page Flow Analysis
AI evaluates entire user journeys across connected pages. Cross-page consistency checks for:
- Navigation patterns and wayfinding
- Visual design coherence
- Flow logic and task completion paths
- Terminology and labeling consistency

Powered by local Ollama or cloud AI with full vision support — screenshots of each page are analyzed alongside DOM data.

### 💾 Multi-Flow Saves
Save, name, load, and delete multiple flows independently. Each flow stores its pages, connections, notes, and analysis results. Badge on the Load button shows your saved flow count.

### 🧹 Clear Canvas
One-click button to reset the entire flow canvas with a confirmation dialog. Start fresh without reloading.

### 📟 Terminal Logs
Real-time floating terminal overlay showing analysis progress, phase transitions, and errors. Each line is timestamped with color-coded severity.

### 🔄 Session Tracking
Each flow analysis generates a unique session ID. Messages from cancelled or previous sessions are automatically filtered out, preventing stale results from appearing.

### 🔥 Heatmap Improvements
Gradient rendering, legend overlay, and pulse animations for issue markers on the severity heatmap.

### ⭐ Chrome Web Store Rating Prompt
In-app prompt encouraging users to rate the extension after successful analysis.

### 🔒 Privacy Policy Update
Updated privacy policy covering Flow Analysis data handling, BYOK transparency, cloud API provider details, and developer information.

### Architecture
```
Flow Builder (full-screen canvas)
    ↕ chrome.runtime.sendMessage
Service Worker (relay)
    ↕ fetch (with sessionId tracking)
Flow Manager (analysis orchestrator)
    → Screenshot capture per page (800×600 downscale)
    → AI evaluation (page-by-page + cross-page synthesis)
    → Results aggregation + terminal logging
    ↕
AI Provider:
  ├── Ollama (localhost:11434) — maxTokens: 8192
  ├── Gemini API — maxTokens: 4096
  ├── OpenAI API — maxTokens: 4096
  └── Claude API — maxTokens: 4096
```

### Storage
```
chrome.storage.local
  ├── synthux_flows[]        — Array of saved flows
  │   ├── id                 — Unique flow ID
  │   ├── name               — User-defined flow name
  │   ├── timestamp          — Save date
  │   ├── pageCount          — Number of pages
  │   └── state              — Full canvas state (pages, connections, notes)
  └── synthux_settings       — Extension settings (unchanged)
```
